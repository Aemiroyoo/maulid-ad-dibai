# Maulid Ad-Diba'i — Kitab Digital

Prototipe awal website statis untuk membaca Maulid Ad-Diba'i.

## Isi
- `index.html` — beranda dan pembaca
- `css/style.css` — desain emerald, cream, antique gold dan responsif
- `js/app.js` — ukuran teks, mode gelap, penanda, navigasi mobile
- `data/` — tempat menyiapkan data transkripsi terstruktur

## Cara menjalankan
Buka `index.html` di browser. Font Amiri dan DM Sans dimuat dari Google Fonts, jadi koneksi internet membantu menampilkan font yang tepat.

## Publikasi GitHub Pages
1. Buat repository GitHub baru.
2. Upload seluruh isi folder proyek.
3. Buka **Settings → Pages**.
4. Pilih branch `main` dan folder `/ (root)`, lalu simpan.
5. Tunggu proses deployment selesai.

## Catatan penting
Teks Arab yang tampil saat ini adalah transkripsi awal dari halaman PDF yang dikirim, bukan edisi final yang sudah ditashih. Cocokkan kembali semua kata, harakat, pemanjangan huruf, dan pengulangan dengan naskah asli sebelum publikasi. Jangan anggap hasil prototipe ini sebagai sumber teks agama yang telah terverifikasi.
